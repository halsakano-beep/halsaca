# oribe — 織部モード

整った案の横に、あえて歪めた「破格の一案」をひとつ添えさせる Claude Code の mod。

## 入れ方

ターミナルの Claude Code で：

```
/plugin install oribe --marketplace halsakano-beep/halsaca
```

`Add marketplace?` に `y`、スコープは user を選ぶ。

## 使い方

- `/oribe` — 入／切を切り替える（`/oribe on`・`/oribe off` でも可）
- 入のあいだ、入力欄の上に「▲ 破格 織部モード中」が出て、ステータス行に「織部」が出る
- 歪める軸は「前提・順序・尺度・視点」。事実確認・コード修正・手順実行では破格を出さない
