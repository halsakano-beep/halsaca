# 人事かるた

架空の職場の性格を、いろは47札でへうげもの寄りに描くLinkedIn連載。巻末で組織づくりの無料勉強会（キャラフル）に案内し、紹介IDのロイヤリティを得る。

## ファイル

| パス | 役割 |
| --- | --- |
| `cards.md` | 47札の一覧（読み札・理論・笑う構造・セミナーの対応） |

## 守ること

- 笑うのは人ではなく、その人をそうさせている構造。毎回、最後の一行で自分にも刺す
- 実在の人・会社（アーテック、前職、取引先）を連想させる要素は入れない
- キャラフルの名前・タイプ名は使わない。土台は公開されている理論（ビッグファイブ、自己決定理論、ダークトライアド）
- ダークトライアドの札は、他人を診断させる書き方にしない。「誰にでも少しある」で締める
- 巻末は毎回静かな一行。厚めの案内は4札に1回
- 案内には「個人の紹介です／紹介報酬あり」を必ず入れる
- アーテックの商品の投稿と同じ週に出さない

## 仕様書の扱い

キャラフルの仕様書はリポジトリに入れない（`private/` は `.gitignore` 済み）。スクリプトには要点を自分の言葉でまとめたメモだけを渡す。
