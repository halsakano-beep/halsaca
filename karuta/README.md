# 人事かるた

架空の職場の性格を、いろは47札でへうげもの寄りに描くLinkedIn連載。巻末で組織づくりの無料勉強会（キャラフル）に案内し、紹介IDのロイヤリティを得る。

## ファイル

| パス | 役割 |
| --- | --- |
| `cards.md` | 47札の一覧（読み札・理論・笑う構造・セミナーの対応） |
| `style.md` | トーンと文体、本文の構成、絵札の画風、公開前の確認 |
| `theory.md` | 3つの理論の要点。札で理論に触れるときの拠り所 |

## 守ること

- 笑うのは人ではなく、その人をそうさせている構造。毎回、最後の一行で自分にも刺す
- 実在の人・会社（アーテック、前職、取引先）を連想させる要素は入れない
- キャラフルの名前・タイプ名・測れる内容には触れない。土台は公開されている理論（ビッグファイブ、自己決定理論、ダークトライアド）で、説明は `theory.md` の範囲に限る
- ダークトライアドの札は、他人を診断させる書き方にしない。「誰にでも少しある」で締める
- 巻末は毎回静かな一行。厚めの案内は4札に1回
- 案内には「個人の紹介です／紹介報酬あり」を必ず入れる
- アーテックの商品の投稿と同じ週に出さない

## 仕様書の扱い

仕様書がなくても運用できる。理論の拠り所は `theory.md` に置く。もし仕様書をもらえたら、`theory.md` の説明が現行のキャラフルと矛盾しないかの確認だけに使い、リポジトリには入れない（`private/` は `.gitignore` 済み）。
